# 二连杆机械臂正运动学

肩关节转 90°，肘关节相对于第一根连杆转 −90°。第二根连杆在世界坐标系里朝哪边，末端会落在哪里？

两根连杆长度分别为 2 和 1，肩关节固定在原点，角度以度表示，逆时针为正。第一根连杆由肩角决定。第二根连杆从肘点出发，其世界朝向是肩角加肘角。源码直接复用[平面坐标变换](../planar-frames/README.md)的 Pose2。

| 肩角 | 相对肘角 | 肘点 | 末端 |
|---:|---:|---|---|
| 0° | 0° | (2,0) | (3,0) |
| 90° | 0° | (0,2) | (0,3) |
| 90° | −90° | (0,2) | (1,2) |
| 90° | 90° | (0,2) | (−1,2) |
| 0° | 180° | (2,0) | (1,0) |

第三组可以揭示把相对角当成世界朝向的错误。肩和肘角抵消后，第二杆水平向右，所以末端应在 (1,2)。

从仓库根目录运行，需支持 C++17 的编译器。

~~~sh
linear=projects/day01-linear-algebra/day01-linear-algebra
g++ -std=c++17 -O2 -Wall -Wextra -pedantic -I"$linear" -Iprojects/planar-frames \
  projects/two-link-arm/main.cpp "$linear/vec2.cpp" "$linear/mat2.cpp" -o /tmp/two-link-arm
/tmp/two-link-arm
/tmp/two-link-arm 90 -90
~~~

无参数时运行五组手算检查，坐标容差为 1e-5。传入两个角度时输出肘点和末端点，角度按一周归约。输入无效时返回退出码 2。Linux GCC 构建与五组检查已通过。实验范围是理想刚体的二维几何位置，连杆长度固定，实际设备的关节限位和误差需另行建模。
