# 随机抽题覆盖率实验

同一个 100 题题库连续出 10 份试卷，每份 20 道不同题。比较两种策略在多次练习中的覆盖率和重复情况。

- **独立抽样**。每份试卷从完整题库等概率抽取 20 道不同题，下一份重新抽取。
- **按曝光次数均衡**。优先选此前出现次数最少的题，次数相同时随机排序。此实验的题库大小是每卷题量的整数倍，预计两轮各覆盖一次题库。

用 Python 3 标准库从仓库根目录运行。

~~~sh
python projects/question-sampling/compare.py
~~~

下表是固定种子 0 至 29 的平均结果。覆盖率是至少出现一次的题目占比，相邻卷重复数是相邻两份试卷的交集大小，曝光极差是出现最多与最少的题之间的次数差。

| 策略 | 平均覆盖率 | 相邻卷平均重复数 | 平均曝光极差 |
|---|---:|---:|---:|
| 独立抽样 | 89.27% | 3.90 | 5.50 |
| 按曝光次数均衡 | 100.00% | 0.44 | 0.00 |

独立抽样的理论期望覆盖率为 `1 − (1 − 20/100)^10 ≈ 89.26%`。均衡组在此配置下每题恰好出现两次，程序会检查这一点，也会检查两种策略的卷内题目互异。相邻重复仍可能发生在两轮覆盖的交界处。

这个实验测量题目曝光，尚未分层考虑题型、难度、知识点和用户记忆状态。可用于评估以后练习模式的选题策略，现有考试系统的抽题逻辑单独维护。
