# 平面坐标系与位姿变换

机械工具端上有一点，在工具坐标系里是 (1,0)。工具原点在世界坐标系的 (2,1)，工具坐标轴逆时针转了 90°。这个点在世界坐标系的哪里？

设局部点为 p，旋转矩阵为 R，工具原点为 t，则世界点为 Rp+t。逆变换先减去 t，再乘 R 的转置。代码复用实验室已有的 Vec2 和 Mat2，长度使用一致的抽象单位，角度用度表示。

| 检查 | 手算预测 |
|---|---|
| 先旋转再平移 (1,0) | (0,1)+(2,1)=(2,2) |
| 先平移再旋转 (1,0) | (3,1) 逆时针转 90° 得到 (−1,3) |
| 工具局部点 (1,0) 转世界坐标 | (2,2) |
| 世界点 (2,2) 转回工具坐标 | (1,0) |

在仓库根目录运行，需支持 C++17 的 GCC 或兼容编译器。

~~~sh
linear=projects/day01-linear-algebra/day01-linear-algebra
g++ -std=c++17 -O2 -Wall -Wextra -pedantic -I"$linear" \
  projects/planar-frames/main.cpp "$linear/vec2.cpp" "$linear/mat2.cpp" \
  -o /tmp/planar-frames
/tmp/planar-frames
~~~

程序检查四项手算预测，坐标误差容限为 1e-5。任一检查失败时返回非零状态。下一次可把同一套坐标变换用于二连杆末端位置计算。

本次在 Linux 上使用 GCC 构建，四项检查全部通过。逆变换输出的 Y 约为 −4.37×10⁻⁸，在容差内还原为 0。
