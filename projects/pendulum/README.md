# 单摆仿真与能量漂移

理想单摆在没有阻力时能量守恒。同一套显式欧拉更新分别用 20 ms 和 5 ms 的步长运行 10 秒，检查步长缩短后能量漂移会怎样变化。

取摆长 1 m、重力加速度 9.81 m/s²，从 30° 静止释放。由拉格朗日方程得到角加速度为 `−g sin(θ)/L`。每一步用旧状态同时更新角度和角速度。每单位质量的能量由动能和势能相加，最低点为势能零点。[原有力学推导资料](../../docs/physics/day-01/)

预测是 5 ms 的最大相对能量漂移小于 20 ms。独立检查第一步时，角度应保持 30°，角速度应变为 −0.0981 rad/s。

从仓库根目录运行，需支持 C++17 的编译器。

~~~sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic projects/pendulum/main.cpp -o /tmp/pendulum
/tmp/pendulum
~~~

Linux GCC 实测如下。相对漂移以初始能量为分母，最大值取每一步的绝对漂移。

| 步长 | 10 秒末漂移 | 最大绝对漂移 |
|---:|---:|---:|
| 20 ms | +460.8261% | 460.8261% |
| 5 ms | +59.1184% | 59.1184% |

程序检查平衡点、第一步手算和步长对照，失败时返回非零退出码。5 ms 组虽有改善，10 秒末仍多出约 59% 的能量。这组结果适合展示显式欧拉的误差，若要用于定量仿真，还需更换积分方法并验证误差。
