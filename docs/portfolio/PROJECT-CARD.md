# 项目卡

复制下列内容作为新实验的起点。初版能写清一个问题、一个预测和一次验证即可。

## 要解决的问题

- 概念：这次学到的知识点是什么？
- 场景：它能解释、预测或改善哪件具体的事？
- 验收：什么输入、输出或观测结果能说明它起作用？

## 预测与最小实现

- 动手前的预测：给出一组输入与可手算或独立核对的预期结果。
- 运行入口：写出环境、命令和预期输出。
- 实现范围：注明输入、输出、单位、假设和已支持的情况。
